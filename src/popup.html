Markdown Viewer

Markdown, made for reading.

Preview Markdown, make temporary edits, and save files.

How to use

Open a Markdown URL directly to preview it. Changes to auto preview take effect after reloading the document.

Choose Edit to make temporary changes, then Save file to download them. Reloading restores the original; changes are never sent to the server.

For local files, open Chrome's extension settings, select this extension's Details, and enable Allow access to file URLs.

HTML and JSON pages are left unchanged. For plain text, use the preview button above.
