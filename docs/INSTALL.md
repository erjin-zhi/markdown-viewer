# 安装 Markdown Viewer

需要 Chrome 128 或更新版本。

1. 解压安装包。
2. 在 Chrome 地址栏输入 chrome://extensions。
3. 开启右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择含有 manifest.json 的解压文件夹。
5. 刷新已打开的 Markdown 页面。

如果已加载本地版本，在扩展管理页面点击 Markdown Viewer 的「重新加载」，再刷新文档。

预览本地 .md 文件：在扩展「详情」中开启「允许访问文件网址」。

编辑仅在本页内存中生效。保存文件会下载编辑后的 Markdown，刷新页面会恢复原文。
