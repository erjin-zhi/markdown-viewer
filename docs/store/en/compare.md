# Release checklist

Prepare the documentation for the next public release.

## Documentation

- Review the quickstart guide.
- Add a code example for the documents API.
- Keep the installation steps in a separate file.
- Check every link before publishing.

## Quality checks

- Test the preview with a short document.
- Confirm that headings appear in the contents panel.
- Review tables and code blocks in light mode.
- Save the final Markdown file locally.

## Release notes

The current release improves document reading and editing.
Publish the package after the final review.
