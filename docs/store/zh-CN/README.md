# v1.4.1 中文商店素材

与英文素材一起从最终 `release/Markdown-Viewer-v1.4.1.zip` 生成，展示新版单行顶栏、预览/编辑入口及编辑区内的差异对比。

- `preview-1280x800.png`：浅色预览。
- `dark-1280x800.png`：深色预览。
- `diff-1280x800.png`：原文和修改后内容的差异对比。
- `promo-440x280.png`：中文小型宣传图，仅本地留存，不上传。

全部是 RGB PNG、无透明通道。中文（中国）和中文（台湾）的界面统一使用简体中文，所以同一套三张截图分别上传到 `zh_CN` 和 `zh_TW` 的“以当地语言显示的屏幕截图/视频”。小型宣传图块只有全球通用配置，统一使用 `../en/promo-440x280.png` 英文版；本目录的中文宣传图保留在本地。具体商店上传状态见 `../listing.md`。

复现方法见 `../en/README.md`；双语捕获脚本为 `scripts/capture-store-assets.js`。
