# Markdown Viewer v1.4.0

2026-11-13

- 新增完整中英文界面，覆盖扩展菜单、阅读与编辑工具栏、差异对比、提示和无障碍标签。
- 默认跟随浏览器语言：中文浏览器显示简体中文，其他语言显示英文；支持手动选择并记住设置。
- 切换语言立即同步已打开的预览页，保留草稿、当前视图、差异导航、滚动位置和分栏宽度；文档正文不变。
- 调整英文界面的窄屏布局，扩展名称和说明随浏览器语言显示。

验证：14 组单元测试、37 项语言界面检查，以及原有预览、编辑和差异对比共 117 项回归检查全部通过。已验证中文地区变体和其他语言回退，以及 320–1280px 的英文布局；构建与安装包完整性检查通过。详细记录见 [TESTING.md](../../TESTING.md)。
